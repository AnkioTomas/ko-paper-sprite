# 月读首页组件、快捷面板与界面皮肤

## 首页组件（`moon_source.lua` → `provides.home_widgets`）
都是**只读视图**：在存档的副本上按当前时间结算后显示，不写存档，不在组件里玩；点按全屏打开阁楼对应页面。

| 组件 id | 名称 | 内容 | 点按 |
|---|---|---|---|
| `ext.papersprite.home` | 阿页 | 图标 + 近况两行（原有卡片） | 打开阁楼 |
| `ext.papersprite.attic` | 阿页的阁楼 | 当前阁楼画面（季节 / 夜晚、在家 / 出门、摆的特产、来访小客人）+ 一行近况 | 打开阁楼 |
| `ext.papersprite.postcards` | 阿页的明信片 | 两种模式：**最近列表**（缩略图 + 地点 · 天气 + 短句 + 日期）/ **迷你墙**（4 列缩略图网格）；新的在前，「新」角标；标题行带翻页条（n / m） | 点某张打开那张；点空白打开明信片墙 |
| `ext.papersprite.cabinet` | 纪念物柜 | 已收集特产图标 + 数量，标题「纪念物柜 n/48」；放不下的最后一格显示 +N | 打开特产柜 |

### 版式（与月读自带组件一致）
- 标题行：左标题（title 字号），右灰色小字（「32 张 · 新 2」「收集 7 / 48」），明信片多页时右侧是翻页条。
- 阁楼：中 / 大 = 标题 + 通栏画面 + 近况两行；被首页压矮放不下时自动改成左图右字（小号「阿页的阁楼」+ 近况 + 灵感）。
- 「阿页」近况卡被压矮时先去掉小字行，再并成一行，不溢出。
- 空状态：明信片「墙上还空着 / 阿页旅行时会寄明信片回来」，纪念物柜「柜子还空着 / 阿页每趟旅行回来都会带一件」，居中显示。

### 设置（首页编辑态里组件的设置按钮，`settings(desktop, id)`）
- 尺寸：小 / 中 / 大（决定默认高度和行数）。
  - 阁楼：小 = 左图右字一行；中 / 大 = 通栏画面（高 0.42 / 0.5 宽）+ 两行字。
  - 明信片列表：2 / 3 / 5 行；迷你墙：1 / 2 / 3 行 × 4 列。
  - 纪念物柜：1 / 2 / 4 行。
- 明信片另可选「最近列表 / 迷你墙」。
- 设置存在扩展自己的月读配置里（`w_<组件>_size`、`w_postcards_mode`），保存后发 `home_refresh` 重建首页。

### 高度与适配
- `heightRange` 按所选档位和组件宽度报内容高度；用户在月读里把高度改成像素 / 填充，或者整页放不下被等比压缩时，
  组件按实际分到的高度重新算能放几行（至少一行；纪念物柜连一行都放不下时缩小图标）。
- 内容贴卡片左上；卡片框、文字、翻页条用月读 `ui.themes`（Box / Text / Pager），拿不到主题时退回 KOReader 原生控件。

### 性能（墨水屏）
- `ui/compose.lua` 把分层画面（背景 + 装饰 + 访客 + 天气）一次合成到离屏位图，按「画面签名 + 尺寸」缓存（最多 24 张，最久未用先释放）。
  缩略图、图标同样走这份缓存，重绘不再解码缩放 PNG。
- 每次绘制前比对显示数据签名（`widget_data.sig`），变了才重建内容。
- 数据层 `ui/widget_data.lua` 是纯函数（headless 测试覆盖）。

## KOReader 顶部菜单里的「阿页」Tab
从顶部下拉 / 点顶部打开的 KOReader 原生菜单（TouchMenu）里多一个「阿页」Tab（自绘图标 `assets/icons/papersprite.tab.svg`：折角书签 + 两个圆点眼睛，24 网格 1px 线，同 KOReader mdlight 风格；文件缺失时用自带 bookmark），**文件管理器和阅读中都有**。
内容：阁楼卡（通栏阁楼画面 + 近况一行 + 灵感 / 新明信片小字）+ 一行快捷按钮「收拾行囊 / 小铺 / 明信片墙 / 特产柜」。
点阁楼卡打开阁楼，点按钮打开对应页（先关菜单，下一帧全屏打开）。月读主题样式，拿不到主题时 KOReader 原生按钮 / 文字。

### 怎么做的（照月读快捷面板 `book.koplugin/features/panel/native.lua`，月读不改）
| 月读 | 本插件 `papersprite/ui/komenu.lua` |
|---|---|
| patch `FileManagerMenu.setUpdateItemTable`、`ReaderMenu.setUpdateItemTable` / `onShowMenu`，往 `tab_item_table` 插带标记的 Tab（`_book_quick_panel` / `_book_reader_panel`，`remember = false`） | 同样 patch 这几个函数，插 `{ icon = "home", remember = false, _papersprite_attic = true }`；已有就不插。位置在月读面板 Tab 之后（没有月读时排第一） |
| patch `TouchMenu.updateItems`：命中自己的标记且是触屏时 `renderPanelContent` 自绘（Tab 栏 + 内容 + footer，重算 dimen，setDirty） | 同样 patch，命中 `_papersprite_attic` 时自绘阁楼卡 + 按钮；其它 Tab（包括月读的）照常往下走原函数 |
| `syncBarSeparator`：让 Tab 栏选中框落到自绘 Tab | 同样处理 |
| 非触屏设备用原生条目填 Tab | 同样：打开阁楼 / 收拾行囊 / 小铺 / 明信片墙 / 特产柜 |

插件 `main.lua` 的 `init()` 里安装（插件在文件管理器和阅读器里都会初始化），并对当前菜单立即补一次 inject。
全部 pcall：自绘失败时退回原生 `updateItems`，菜单照常可用。
**脆弱点**：依赖 KOReader TouchMenu 内部字段（`item_group`、`bar`、`footer`、`page_info_*`、`menu_container`）和菜单模块的函数名；
和月读同一套假设，KOReader 改了这些两边会一起受影响。

### 之前的「自己的下拉面板」
`e19af4c` 做的独立下拉面板（`ui/paper_panel.lua`）和阁楼组件上的下滑触发**已删除**——顶部菜单 Tab 已经覆盖同样的用途，留着是重复入口。
月读快捷面板的「阿页」开关和 KOReader 手势动作「阿页的阁楼」（Dispatcher `papersprite_panel`）现在都直接打开阁楼。

## 全屏界面皮肤（`ui/screen.lua`）
- 默认 `ui_skin = "auto"`：只要能 `require("ui.themes")`（装了月读，不论从月读还是 KOReader 菜单打开）就用月读组件：
  标题栏（TitleBar，带关闭图标）、卡片 / 图片框（Box）、文字（Text.box / Text.line）、按钮（Button）、翻页条（Pager）、主题色。
- **每个组件单独 pcall**：某个主题组件失败只有它退回原生控件，其余照常。
- `ui_skin = "native"`：强制 KOReader 原生控件（用来对照 / 排错）。
- 已在模拟器里对照：月读主题 paper / bold / soft 与原生皮肤。

## 页面版式（统一）
- 标题栏：**左 = 返回上一级**（阁楼主页是 ✕ 关闭），中 = 标题，**右 = 视图切换**（目前只有明信片墙：列表 / 网格）；没有就留空保持居中。
  月读 TitleBar 的 left/right 图标槽（arrow_back / close / view_list / grid_view），原生皮肤同样排布（‹ 返回 / ✕ / 文字）。
- 状态卡（图标 + 标题 / 说明 / 小字）放每页最上面；卡片网格（图标、标题、小字、一行说明，✓ 表示已选 / 已摆）；
  小节标签用小号灰字；空状态是一张居中的卡（标题 + 提示）。能溢出的列表都分页（n / m）。
- 阁楼：画面 → 状态卡（在家 / 快出门 / 在路上 + 灵感 / 明信片）→ 六个入口卡（收拾行囊、小铺、明信片墙、特产柜、剪贴簿、来客簿）→ 来客 / 最近两条。
- 剪贴簿：收齐 n/40 页 → 地点卡（去过次数、特产进度，分页）→ 地点详情（特产清单、惦记 ✦5）。
- 来客簿：见过 n/12 → 访客卡（未见为？？？）→ 详情（来访 / 离开文案）。
- 收拾行囊：藤筐状态卡 → 三格（干粮 / 护身物 / 随身小书，当前格 ✓）→ 当前格可放的物品卡（存货 / 常备 + 效果，分页 6），放好自动跳到下一空格。
- 单张明信片：画面 → 地点 · 天气 / 短句 / 日期 · 第 i/n 张，翻页条在明信片之间前后翻。
- 特产柜：收集 n/48 · 阁楼摆了 k/4 → 特产卡（×数量、是否摆在阁楼、短句，分页 6）→ 点开详情（大图标、短句、摆到阁楼 / 收起）。
- 小铺 / 物品详情：同上（状态卡 + 效果小节）。

## 翻页
- 所有分页的页面（明信片墙网格 / 列表、小铺、收拾行囊、特产柜、单张明信片）：翻页条**贴在屏幕底部**。
  月读在时用月读自己的 `ui.themes.widgets.pager`；原生皮肤是 KOReader 列表同款页脚（« ‹ n / m › »，无边框图标按钮，可跳首页 / 末页）。
- 左右滑翻页（向左 = 下一页），同 KOReader 列表。
- 每页数量按屏幕剩余高度算（`view.<list|grid|shelf>.fit` 回报给游戏，游戏记住后重排）：不裁切最后一行，也不在底部留大块空白；
  明信片列表剩余空白超过半行时多放一行并略缩小缩略图。

## 返回方式
子页面（收拾行囊、小铺、明信片墙、特产柜、物品详情、单张明信片）不再有底部「回阁楼 / 回小铺 / 回明信片墙」按钮：
标题栏左上角的按钮就是返回上一级（`Game.PARENT`：详情 → 小铺，单张 → 墙，其余 → 阁楼），阁楼页上它才是关闭。腾出的高度留给内容；两种皮肤都一样。

## 明信片墙
- 两种视图（`wall_mode`，墙页底部按钮切换）：
  - 网格：3 列 × 4 行 = 每页 12 张，缩略图 + 地点名，「新」角标；
  - 列表：每页 4 张，左缩略图，右边「地点 · 天气 / 短句 / 日期」。
- 新的在前；翻页条显示 n / m（月读 Pager，原生退回「上一页 / n / m / 下一页」）。
- 「新」= 进墙前还没看过的；同一次进墙里翻页、切视图、看单张回来，角标都保留。

### 阁楼主页分页
第 1 页：画面 + 状态卡 + 四个入口；第 2 页：来客卡 + 「最近」日志卡；日志多时往后翻页。翻页用同一套 pager（Moon pager / 原生页脚 + 左右滑）。
每页放几条按屏幕高度量出来：screen 报回 `(full, lead)`，full 是一页能放几条，lead 是来客卡占掉几条。画面放不下时会缩小再排一次，所以什么尺寸的屏幕都不会被截掉。

### 无边框 + 事件时间
- 卡片一律不描边（状态卡、入口卡、日志卡、小铺/特产柜/行囊卡、首页小组件、画面框、Tab 按钮）：靠留白分开，列表之间用 1px 浅灰细线；月读皮肤沿用主题卡片底色，只把 border 置 0（`noBorder`）。「新」角标改成黑底白字小块。
- 日志带时间：`s.log_at` 跟 `s.log` 一一对应（旧存档前面补 0，不显示时间）。显示规则 `Game.when`：1 分钟内「刚刚」、1 小时内「N 分钟前」、当天内「N 小时前」、更早「MM-DD HH:MM」（和明信片日期同一格式）。目前只有阁楼「最近」列出事件；首页小组件和菜单 Tab 不列日志。
