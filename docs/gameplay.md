# 玩法说明

## 循环
1. **收拾行囊**：干粮 / 护身物 / 随身小书各放一样。放满三格即「收好」。
2. **等它出门**：收好后过一阵，阿页自己出发，阁楼变空，桌上留纸条。
3. **明信片**：旅途中按时寄回 1–2 张，贴上明信片墙。
4. **回家**：带回一件特产（特产柜），行囊清空；有时会有小访客来串门。
5. **布置阁楼**：在特产柜里点一下特产，就能把它摆进阁楼（最多 4 样，右墙矮架的架顶和中层），再点一下收起。阁楼背景会随季节（春夏秋冬，按月份）和夜里（21 点后、6 点前）变化。
6. **地点剪贴簿**：40 个地点各一页。去过一次且该地特产收齐，这一页就算收齐。可用灵感（✦5）「惦记」某地，下一趟旅行直达那里。
7. **来客簿**：12 位小客人来过一次就记下来（含初次来访时间）；稀有访客来得少。
8. **小铺**：用灵感换更多行囊物品，不同物品会把阿页引向不同地方。
   货架是 2 列 × 3 行的物品卡（图标、名字、✦ 价格、已有几个、一行效果），翻页条 n / m；
   顶部分类「全部 / 干粮 / 护身物 / 随身小书」。点卡片进详情：手写介绍 + 实际效果（由数据算出，见下）+「买一个」。
   效果行由 `Game.itemEffect` 从数据生成，和真实机制一一对应：
   `tags` → 「爱去 …」（目的地按地点类型加权，每个匹配 +2）；`hours_bias` → 「旅程 ±N 时」；
   非常备物品出门时带走一个用掉，常备物品（价格 0，不在小铺卖）不会用完。物品本身不影响明信片张数和访客。
9. 回到第 1 步。在月读里且 AI 已配置时，每趟旅行的文案由 AI 现写，见 [ai.md](ai.md)。没有失败、没有惩罚。

## 数值（原创，骨架版本）
| 项目 | 数值 |
|---|---|
| 收好 → 出门 | 20–90 分钟（随机） |
| 旅程时长 | 基础 3 小时 + 行囊修正 + 0–11 小时随机，夹在 3–30 小时 |
| 行囊修正 | 茶包 +2h、地图册 +3h、短诗 −1h |
| 每趟明信片 | 1 张（50%）/ 2 张（35%）/ 3 张（15%），在旅程中均匀寄出 |
| 去哪儿 | 40 个地点，基础权重 1，行囊物品每命中一个地点标签 +2 |
| 特产 | 每趟 1 件，每个地点 1–2 种，共 48 种，都有图标，收进特产柜，可摆进阁楼 |
| 访客 | 回家时 40% 有客人，12 位按权重挑一位（墨点虫 .20 最常见，印泥熊 .04 最少见），各有 2 种姿势；停 1–6h，走时留 2–6 灵感，见 `data/visitors.lua` |
| 不重复 | 收到过的明信片（组合 + 文案）不会再寄，同一趟也不重复；某地点全部收齐后才重复最久没见的 |
| 明信片组合 | 40 地点 × 2 背景 × 24 姿势 × 25 小物 × 10 天气/时刻 ≈ 48 万种画面（钓鱼/坐船等只在水边，室内不下雨雪） |
| 短句库 | 地点句 120 + 天气句 30 + 姿势句 16，AI 句另计 |
| 小铺 | 33 种非常备物品，3–12 灵感（共 36 种，干粮/护身物/小书各 12） |
| 天气 | 按出片时的季节 × 钟点加权，节日有自己的偏好（见 [festival.md](festival.md)） |
| 开局灵感 | 10 |
| 阅读换灵感 | 每 20 次有效翻页 = 1 灵感；同一分钟内只算一次；只认相邻翻页（页码差 1–3），改字号 / 旋转 / 进度条跳转不算 |
| 惦记地点 | ✦5；下一趟直达该地，用过即清；阿页在路上时不能惦记 |
| 剪贴簿 | 40 页（各地特产收齐且去过 ≥1 次） |
| 来客簿 | 12 位（来访一次即收录） |
| 常备物品 | 价格为 0 的物品（饼干、铅笔头、地图册）取之不尽 |

## 离线结算
旅行不依赖后台运行：每次打开阁楼（或首页卡片绘制）时，用「上次 → 现在」的真实时间一次性算完所有出门、寄信、回家。关机几天再打开也一样。

## 调试：debug_fast
开启后「分钟 → 秒，小时 → 10 秒」，几分钟就能走完一趟。
- KOReader：`.moon/game/paper-sprite/save.lua` 里 `["setting_debug_fast"] = true`
- 月读：`.moon/settings/ext.papersprite.lua` 的 `settings.debug_fast = true`
- 代码：`host:setSetting("debug_fast", true)`

## 扩展玩法

- **阅读联动**：`core/reading.lua` 记翻页并按书名 / 关键词判类型（`GENRES`）；末页附近 = 读完，进 `bookmarks`（读书墙）并 +5 ✦。类型写入 `read_tag`，48 小时内选地点 +3 权重。
- **成长**：`core/quest.lua` 的 `exp/level` 分 5 阶。
- **旅途事件**：`data/events.lua`，出发时按概率（30%，5 阶后 40%）掷骰；效果在出发（时长 / 邮件）与归来（特产加倍 / 灵感 / 道具）结算。
- **访客互动**：访客在家时「招待」送特产，一人一次；交情 3 / 5 / 8 阶段有回礼；访客可带 `request`。
- **委托 / 成就**：`data/quests.lua`、`data/achievements.lua`；`Quest.note` 记数，`Quest.check` 在 `settle` 末尾自动发成就。
