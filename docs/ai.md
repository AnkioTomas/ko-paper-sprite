# 可选 AI 文案层

阿页的旅行完全可以离线进行：所有地点、明信片短句、特产说明、访客台词都有本地文案库。
在 **月读** 里、且月读的 AI 已经配置好时，游戏会额外请 AI 为每一趟旅行写一套专属文案。

## 来源与开关
- 只复用月读现有能力：`require("ai")`（月读 `book.koplugin/ai.lua`）的 `isConfigured()` 与 `jsonExtract(messages, opts, cb)`。
- 端点、密钥、模型、超时都来自月读设置（`settings/ai.lua`），本插件**不新增任何密钥或网络配置**。
- 回答语言跟随月读「AI 回答语言」设置：请求带 `localize = true`，月读把系统提示词里的「简体中文」换成所选语言并追加用语要求；英文回答的字数上限放宽 3 倍（`Story` 的 `slack`）。
- 纯 KOReader 宿主没有 `host:ai()`，永远走本地库。
- 关闭：月读扩展设置 `ext.papersprite.settings.ai_story = false`。

## 什么时候请求
`core/story.lua` 的 `Story.maybeRequest`：阿页**出门那一刻**（结算出 `away` 时）发起一次，每趟最多请求 `Story.MAX_TRIES`（2）次：失败或超时会放开 `ai_req`、记 `ai_fails`，下次刷新再试一次。提示词会带上出门当天的节日和最近寄过的几句话。只有界面开着（或打开时刚好在旅途中）才会发起；整趟旅行在界面关着时就结束了的，只能用本地文案。
请求是异步的，界面照常使用；结果回来后：
1. 重读存档，确认还是同一趟（`trip` 编号相同、仍在旅途中）；
2. 校验并写入 `sprite.ai`，落盘；
3. 之后寄到的明信片、回家旁白、特产小注、访客台词优先使用 AI 文案，并**随明信片一起存进存档**（`postcard.line`、`postcard.ai = true`、`souvenir_notes`），以后离线也能看。

## 提示词与输出约束
系统提示：阿页的设定、原创书中世界、简体中文、第一人称、不提真实书名 / 作者 / 游戏 / 品牌 / 人物、不写暴力悲伤说教、只输出 JSON。
用户提示给出：地点名与参考语气、行囊、特产、每张明信片的天气 / 姿势 / 小物。
要求的 JSON：
```json
{
  "lines": ["每张明信片一句，≤40 字，数量与明信片相同"],
  "narration": "回家时的一句旁白，≤80 字",
  "souvenir_note": "特产小注，≤30 字",
  "visitor_line": "访客来串门时的一句描写，≤40 字"
}
```

## 校验与回退（`Story.validate`）
- `lines` 数量必须够、每句非空且不超长，否则**整套丢弃**（保证同一趟风格一致）。
- 去掉换行与引号；含 `< > { }` 或网址的句子视为不合规。
- 其他字段不合规时单独丢弃。
- 未配置 / 离线 / HTTP 失败 / JSON 解析失败 / 超时（`Story.TIMEOUT` = 180 秒后取消）/ 抛错：全部静默，用本地文案库。

## 去重
- 同一回复中两句（去空白与标点后）相同：整套丢弃。
- 寄达时 AI 句与存档里收到过的任何一句相同：这张改用本地句（`texts` 表）。
- 画面组合本身在出门时已按 `collected` 去重，见 [data-format.md](data-format.md#去重)。

## 测试
`spec/run.lua` 用桩 AI 覆盖：成功写入并缓存、不合规整体拒绝、调用抛错、永不回调（超时），四种情况旅行都正常完成；另测每趟返回同样句子时只有第一次被采用。

## 其他触发（`core/story.lua`）

都走同一个请求外壳 `Story.ask`（无 AI / 抛错 / 超时 / 校验不过都静默放弃，各自最多重试 `MAX_TRIES` 次）：

- **旅行文案**：出门期间在 `Game:tick` 里请求；JSON 还可带 `note`（≤24 字出门纸条）。
- **迟到补写**（`maybeRecap`）：整趟在界面关着时走完，`Travel` 回家时留下 `s.recap`；下次打开补请求，`Travel.applyRecap` 改写那几张明信片的句子（同样去重）和特产小注。
- **预取（提前要好，用时不等）**：
  - 今日小纸条（`maybeDaily`）：池 `s.pool.notes` 按时段（清晨 / 白天 / 傍晚 / 夜里）存，每个时段 3 张；阿页在家时某个时段见底就后台一次补一批（≈每 2 天一次请求），每个「日期 + 时段」从池里取一张显示在阁楼状态栏；池空时用 `data/notes.lua` 本地池。
  - 来客反应（`maybeGuest`）：访客一到就预取两句（送了想要的 / 送了别的）和一句「在家」描写，存在 `visitor.react` / `visitor.line`，首页招待时直接显示，不等请求。
  - `core/pool.lua`（每次刷新见底才补，互不阻塞，各自最多重试 `MAX_TRIES` 次）：
    - 明信片句：`pool.lines[地点]`，每次最多 4 个地点、每地点 4 句，按去过的次数从多到少补；寄达时没有本趟 AI 句就取池里一句（收到过的丢掉）。
    - 旅途事件：`pool.events[事件]` 每个事件 2 种改写，写进日志时取一条，意思与效果不变；池空用原文。
    - 委托托词：新委托一出现就批量要一句便签式托词，存进 `quests.list[i].flavor`，显示在委托页。
